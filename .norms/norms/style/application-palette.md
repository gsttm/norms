# Use the application palette

Use these colors for Norms-owned styling in the terminal UI and VS Code extension:

| Role | Hex |
| --- | --- |
| Primary | `#283A8F` |
| Dark | `#1F2F6B` |
| Bright accent | `#3E57C4` |
| Soft tint | `#EEF1FA` |
| Ink | `#111318` |
| Background | `#FAFBFC` |

Do not introduce other brand colors. Preserve host-provided semantic colors when platform behavior or accessibility requires them.
